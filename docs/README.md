## Document Database Manager<sup>SiYuan-Attribute-Panel</sup>

Manages **document ↔ database** binding and listing. Does **not** inject an under-title attribute panel.

Use SiYuan’s native database area to view/edit field values.

### Features

1. Binding rules: notebook or path prefix → default database (`avID` + database block id)
2. Dock: current-doc bindings, bind/unbind, list docs in a database
3. Field editing stays native
