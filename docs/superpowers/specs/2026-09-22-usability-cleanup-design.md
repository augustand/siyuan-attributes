# 易用性优化（第 3 刀）：管理清理

**日期：** 2026-09-22  
**状态：** 已批准（对话「继续优化」）  
**前置：** 第 1、2 刀

## 问题

早期「直接写文件」创建的库缺少镜像块关系：绑定后标题下无属性，且会被思源自动解绑。用户名单里可能残留这类坏库。

## 目标

1. 打开 Dock / 设置时检测「我们的库」健康度（`getMirrorDatabaseBlocks` 有镜像块）  
2. 异常库在列表标「不可用」  
3. 提供「清理异常库」一键从名单移除（不删思源里的 AV 文件，避免误伤）  
4. 绑定失败时文案引导清理  

## 非目标

- 自动修复/迁移坏库数据  
- 从思源磁盘删除 AV  

## 检测

`avID` → `/api/av/getMirrorDatabaseBlocks` → `refDefs.length >= 1` 为健康；否则异常。  
`getAttributeView` 失败也视为异常。
