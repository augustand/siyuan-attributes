# 易用性优化（第 2 刀）：建库体验

**日期：** 2026-09-22  
**状态：** 已批准（对话「继续」）  
**前置：** 第 1 刀日常路径

## 目标

1. 新建时默认只需填**库名**；笔记本自动推断  
2. 推断顺序：当前文档所在笔记本 → 上次创建用的笔记本 → 列表第一本  
3. 「更换存放位置」折叠展示笔记本选择，并记住上次选择  
4. 创建成功后**不强制打开**库主文档（避免打断当前文档）；可在列表点「打开」

## 非目标

- 自动新建专用笔记本  
- 坏库清理（第 3 刀）

## 设置字段

`ownedDbNotebookId?: string` — 上次创建选用的笔记本 id
