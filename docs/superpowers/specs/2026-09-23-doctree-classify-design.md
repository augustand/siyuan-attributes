# 文档旁归类（主路径挪出 Dock）

**日期：** 2026-09-23  
**状态：** 已实现  

## 目标

日常「写文档 → 归类」贴在文档树，不依赖打开 Dock。

1. 文档树右键：`标为任务` / `标为项目` / `标为产品`  
2. 每类有一个**主库**（`ownedDbPrimaryByType`）；该类只有一个库则即主库；新建该类库时自动设为主库  
3. 点击后：静默互斥挂到该类主库 + 补齐模板列 + 短 toast；无主库则引导新建（预填类型）  
4. Dock 仍负责：建库、名单、异常修复；不再是日常挂接的唯一入口  

## 实现要点

- 菜单注册在插件级 `DoctreeClassifyHost`（`onload` 常驻），**不依赖 Dock 打开**  
- 核心逻辑：`services/doctreeClassify.ts`  
- Dock 通过 `settings-changed` 事件同步名单  

## 非目标

- 路径自动规则引擎  
- 改思源原生「添加到数据库」  
- 多级子菜单（本刀三项平铺即可）  
- 同类型多库时的「设为主库」显式按钮（挂接即记为主库）
