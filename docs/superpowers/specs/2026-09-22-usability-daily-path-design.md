# 易用性优化（第 1 刀）：日常路径

**日期：** 2026-09-22  
**状态：** 已批准（对话确认「继续」）  
**范围：** 仅 Dock「当前文档优先」；设置页仅改文案。建库默认位置、坏库清理见后续刀。

## 问题

Dock 里「我们的库 / 导入 / 当前文档」并列，日常「打开文档 → 加入库」不够显眼；无库时主按钮直接禁用，路径断裂。

## 目标

1. Dock 上半：当前文档（主操作）  
2. Dock 下半：我们的库（新建 + 列表）  
3. 「导入已有 / 导入本页」收入「更多」折叠，默认收起  
4. 无库时主按钮引导「先新建库」  
5. 添加成功后明确提示看标题下原生属性，并刷新绑定列表  
6. 设置页文案指向 Dock 做日常添加  

## 非目标

- 文档树右键菜单  
- 改绑定 API / 建库实现  
- 坏库自动修复  

## UI 结构

```
[当前文档]
  大按钮：添加到数据库…  |  无库时：先新建库
  已加入列表 / 空态文案

[我们的库]
  [新建]
  列表（打开 / 移除）

[更多 ▸]  （默认折叠）
  导入已有
  导入本文档中的数据库
```

## 成功标准

- 打开文档后，Dock 第一眼是「添加到…」  
- 无库时能从主按钮进入新建  
- 导入不挡主路径
