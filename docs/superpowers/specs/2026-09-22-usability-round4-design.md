# 易用性优化（第 4 刀）：快加 / 右键 / 按库看文档 / 引导

**日期：** 2026-09-22  
**状态：** 已批准（对话「都做」）

## 1. 一键快加

- 设置 `ownedDbLastAvID`：上次成功加入的库  
- Dock 当前文档主按钮：若上次库仍健康且未绑定 →「加入「名称」」；否则「添加到数据库…」  
- 次要：小按钮「选择其它…」打开名单对话框  

## 2. 文档树右键

- `plugin.eventBus.on("open-menu-doctree", …)`（若不可用则 `click-blockicon` / 文档菜单等价事件）  
- 菜单项「添加到我们的库…」→ 打开与 Dock 相同的选库对话框（传入当前文档 id）  

## 3. 按库看文档

- Dock「我们的库」行增加「文档」；展开/对话框列出 `getAttributeViewPrimaryKeyValues` 结果，点击打开  

## 4. 首次引导

- 无库：当前文档区短引导「① 新建库 ② 添加到数据库 ③ 在标题下编辑」  
- 有库未绑定：提示点主按钮  

## 非目标

- 自动强制绑定  
- 修改原生「添加到数据库」菜单
