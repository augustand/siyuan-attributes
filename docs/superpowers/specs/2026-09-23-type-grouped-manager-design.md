# 按类型的管理台（管理工作台 A）

**日期：** 2026-09-23  
**状态：** 已批准（对话选 A +「继续吧」）  
**前置：** `2026-09-22-business-db-types-design.md`

## 问题

插件已能按类型模板建库，但 Dock 仍是平铺名单 + 通用「添加到数据库」。用户目标是**管理工作**：建好模板库、管好这些库、方便把文档挂进对应类型库。类型感不足，挂接仍像选任意库。

## 目标

1. **当前文档**：未挂（或可再挂）时，按**类型**快捷挂接（任务 / 项目 / 产品；通用次要）。
2. **我们的库**：按类型分组展示与管理。
3. 挂接优先级：该类下上次用过的健康库 → 仅一个健康库则直挂 → 多个则打开过滤后的选库对话框。
4. 字段编辑仍完全原生；本刀不做缺列补齐。

## 非目标

- 自动强制绑定 / 路径规则引擎  
- 缺列补齐（刀 C）  
- 按字段查询  
- 改思源原生「添加到数据库」菜单  

## 产品约定

### 当前文档 · 按类型挂

当存在当前 `docId` 且至少有一个健康 owned DB 时：

- 展示类型快捷区（任务 / 项目 / 产品；若有通用库也显示通用）。
- 点击类型 `T`：
  - 0 个健康且 `typeId===T` → toast 提示先新建该类型库（可带打开新建对话框并预填类型）。
  - 1 个 → 直接 `bindDocumentToDatabase`。
  - 多个 → 若 `ownedDbLastAvID` 属于该类且健康且未绑定 → 挂它；否则打开选库对话框，列表仅该类健康库。
- 已绑定的库仍列出名称 + 类型标签 + 移出。
- 保留「选择其它库…」打开全量健康库对话框。

### 我们的库 · 分组

固定顺序：`task` → `project` → `product` → `generic`。  
无库的类型组可不显示（或显示空组+新建，本刀：**无库则隐藏该组**）。  
组标题：`任务 (n)`；组内行：名称、文档/打开/移除（同现有）。

### 成功标准

1. 未挂库文档可一点「任务」挂进任务类库（单库时零对话框）。  
2. 多任务库时优先上次库或弹出仅任务库列表。  
3. 「我们的库」按类型分组。  
4. typecheck + 挂接选择纯函数单测通过。
